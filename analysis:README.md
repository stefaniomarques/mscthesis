# Analysis Scripts

This folder holds the R / Quarto files used for estimation. Add your project's `.qmd`
and `.R` files here, for example:

- `thesis_main.qmd` — master file assembling the full document
- `empirical_analysisv14.qmd` — core ARDL / ECM estimation
- `00_cover.qmd` … `09_appendices.qmd` — individual chapter files
- `header.tex`, `references.bib`, `no-longtable.lua` — supporting LaTeX/Quarto assets

Before pushing, double-check no local file paths (e.g. `~/Downloads/...`) or personal
identifiers are hard-coded into any script.
