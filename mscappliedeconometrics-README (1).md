# Applied Econometrics

Weekly R/Quarto tutorials from the Applied Econometrics module of the MSc Economics
and Data Analytics programme at University College Dublin. Each worksheet works
through a core applied econometric method, mainly using the Wooldridge `WAGE1`
dataset (plus a supplementary air-quality dataset in worksheet 6).

## Contents

| File | Topic |
|---|---|
| `worksheet.qmd` | Data import and exploration in R |
| `worksheet2.qmd` | Regression estimation and marginal effects |
| `worksheet3.qmd` | Log-wage models, interaction terms, Wald tests, and parsimonious model selection |
| `worksheet4.qmd` | Residual diagnostics — leverage, DFBETAS, Q-Q plots, Kolmogorov-Smirnov and Jarque-Bera normality tests |
| `worksheet5.qmd` | Model selection (AIC/BIC), encompassing (J-) tests, and Oaxaca wage-gap decomposition |
| `worksheet6.qmd` | Heteroskedasticity testing — Breusch-Pagan, White, and Goldfeld-Quandt tests |
| `worksheet7.qmd` | Wald hypothesis testing, heteroskedasticity-robust OLS, and IV/GMM estimation |

## Tools

R · `tidyverse` · `stargazer` · `modelsummary` · `car` · `lmtest` · `sandwich` ·
`ivreg` · `gmm` · `fixest`
